# Transformable Box - 3D viewer

Interactive 3D model of a transformable plywood box that converts between
three configurations: **Stool** (two boxes side by side), **Storage** (stacked
vertical cabinet), and **Study desk** (fold-down panel). Built with three.js;
the geometry is generated procedurally in the page - no model file needed.
Works on phones: drag to rotate, pinch to zoom, tap a configuration.

Open `index.html`, or view it live via GitHub Pages.
Each box 450 x 450 x 450 mm; cabinet 450 x 900 x 450 mm; desk panel 450 mm.
